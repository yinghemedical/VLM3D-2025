# End-to-End CT Classification + Report Generation Pipeline

This folder is the public-facing entrypoint for the VLM3D 2025 submission
pipeline. It runs **CT_CLS8 classification first**, then uses the predicted
18-class labels as the prompt condition for the **MedM-VL 8B report model**.
Each case is independent and produces its own result folder.

> U-VLM is used only as an evaluation-protocol reference. The classification
> model is **CT_CLS8**, not a U-VLM classifier.

## Pipeline

```text
CT volume (.nii.gz / .nii / .mha)
        │
        ▼
CT_CLS8
  TotalSegmentator v2.0.1 full-volume anatomy segmentation
  → 7 ROI crops
  → ResEncUNet ROI classifier
  → 3-checkpoint ensemble (sigmoid average)
  → 18-class probabilities
        │
        ▼
prompt
  "may have: ..."
  "does not have: ..."
        │
        ▼
MedM-VL 8B
  SigLIP2-so400m-patch14-384 + Qwen3-8B
  → generated radiology report
        │
        ▼
case.json
  classification probabilities + binary labels
  prompt
  report
```

The classification output is thresholded at `0.5` only to build the prompt;
the full probabilities are retained in the output.

## Layout

```text
pipeline/
  README.md
  run_case.sh                 # one case, fully independent
  run_examples.sh             # a few example cases
  run_3039.sh                 # full CT-RATE valid_fixed batch
  configs/pipeline.env.example
  examples/cases.example.csv
  scripts/
    make_case_manifest.py
    make_case_report_input.py
    collect_case.py
  outputs/                    # generated results (not committed)
```

The pipeline reuses the implementation under `../scripts/classification/`
and `../scripts/report_generation/`; weights and data are external.

## Prerequisites

- CT-RATE-like CT volumes in NIfTI or MHA.
- CT_CLS8 code tree with `nnUNet_results/Dataset665_Totalsegmentator_v201_Anatomy`
  (TotalSegmentator segmentation model) and the three classifier checkpoints.
- MedM-VL 8B checkpoint and local SigLIP2/Qwen3-8B assets.
- `medmvl` conda env for CT_CLS8; `medals_local_test` for MedM-VL inference.
- See `configs/pipeline.env.example`; copy to `pipeline.env` and edit.

The public release should **not** contain CT-RATE images, report text, model
weights, or private cluster paths. Download weights/data under their upstream
licenses and set paths in `pipeline.env`.

## One case

```bash
cp pipeline/configs/pipeline.env.example pipeline/configs/pipeline.env
# edit pipeline/configs/pipeline.env

bash pipeline/run_case.sh \
  /path/to/case.nii.gz \
  my_case_001 \
  pipeline/outputs
```

Output:

```text
pipeline/outputs/my_case_001/
  cases.csv
  classification/
    ct_cls8_predictions.csv
  report_input.json
  report.json
  report.csv
  case.json                 # final per-case result
  logs/
```

`case.json` contains:

```json
{
  "case_id": "my_case_001",
  "image": "...",
  "classification": {
    "probabilities": {"Medical material": 0.01, "...": 0.0},
    "binary_0.5": {"Medical material": 0, "...": 0}
  },
  "prompt": "<image3d>\nGenerate radiology report ...",
  "report": "Findings: ... Impressions: ...",
  "success": true,
  "error": null
}
```

## Few example cases

Edit `pipeline/examples/cases.example.csv` if needed, then:

```bash
bash pipeline/run_examples.sh
```

Each row is processed independently by `run_case.sh`; results go to
`pipeline/outputs/examples/<case_id>/case.json`.

The included examples are CT-RATE public `valid_fixed` cases; no images or
reports are redistributed.

## Full CT-RATE 3,039 cases

Local (requires 4 visible GPUs):

```bash
bash pipeline/run_3039.sh
```

Cluster (submit the two jobs in order):

```bash
batch_cmd run -i VLM3D/configs/classification/ctrate_ct_cls8_full.yaml -y
batch_cmd run -i VLM3D/configs/report_generation/ctrate_report_8b_ctcls8.yaml -y
```

The second job auto-detects `runs/classification/ctrate_valid_ct_cls8/full/ct_cls8_predictions.csv`
and runs the 8B report model with CT_CLS8-conditioned prompts.

Outputs:

```text
runs/classification/ctrate_valid_ct_cls8/full/
  ct_cls8_predictions.csv
runs/report_generation/ctrate_valid_8b/full_predcls_ctcls8/
  predictions.csv
  metrics_nlg.json
  metrics_cls.json
  metrics_crg.json
```

## Reproducibility notes

- CT_CLS8 is an ensemble of three checkpoints; the report prompt uses the
  averaged probability, threshold 0.5.
- The report model uses `sdpa` in this pipeline; no `flash_attn` required.
- The MedM-VL copy has two offline-loading patches (`siglip2.py`, `qwen.py`)
  and a local runtime config is generated by
  `scripts/report_generation/prepare_runtime_model.py`.
- The CT-RATE `valid` split was included in the final 8B fine-tuning data; use
  an external held-out set for a clean generalization number.
- U-VLM evaluation code is used only for the CT-RATE CSV/BLEU/F1 protocol.
